# Security policy

Please report a vulnerability privately and not as a public issue: use **Security → Report a vulnerability** (GitHub's private vulnerability reporting) on this repository. The latest version on the default branch is the one that is covered.

This repository is part of [ai-sdlc-factory](https://github.com/ai-sdlc-factory/ai-sdlc-factory); its [security policy](https://github.com/ai-sdlc-factory/ai-sdlc-factory/blob/main/SECURITY.md) says what is most interesting and how the parts are meant to be separated.
