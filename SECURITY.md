# Security policy

Please report a vulnerability privately and not as a public issue: use **Security → Report a vulnerability** (GitHub's private vulnerability reporting) on this repository. The latest version on the default branch is the one that is covered.

This repository is part of [dev-foundry](https://github.com/OWNER/dev-foundry); its [security policy](https://github.com/OWNER/dev-foundry/blob/master/SECURITY.md) says what is most interesting and how the parts are meant to be separated.
